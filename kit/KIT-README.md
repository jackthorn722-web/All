# Local Service Website Kit — 3 one-page templates

Three complete, hand-built one-page websites for local service businesses:

- `lawn.html` — lawn care / landscaping (light, green, photo-forward)
- `barber.html` — barbershop (dark, charcoal & brass, price menu)
- `groomer.html` — pet grooming (teal & apricot, booking-first)

Every template is a single HTML file with zero dependencies beyond the
included fonts. No frameworks, no build step, no subscriptions.

## What's included in each

Mobile-first responsive layout · tap-to-call buttons · sticky mobile
call/book bar · services/price menu · photo slots · review slots ·
hours & service area · booking-link slots · accessible focus states ·
self-hosted fonts (`fonts/` folder — Instrument Serif, Archivo, Space
Mono, all under the SIL Open Font License).

## How to use (15 minutes)

1. Open the template in any text editor.
2. Replace every ALL-CAPS placeholder ("YOUR PRICE", "YOUR WORK PHOTO",
   "Your Town") with your real details — search for "Your" to find them all.
3. Swap the placeholder slots for your own photos (phone photos work great).
4. Set your real phone number: search for `801) 555-0100` and `+18015550100`.
5. Host anywhere — GitHub Pages, Netlify, or any static host (all free).

## Honesty checklist before you publish

Only claim what's true for YOUR business: licensed/insured, years in
business, guarantees, and reviews must be your real ones. Never publish
the placeholder reviews as if they were real.
