# Outreach scripts

Rules that apply to every message: low volume (10–25/week), individually
personalized, truthful, sent from a real named account, includes a working
opt-out, stops immediately on any "no". This is B2B, CAN-SPAM-compliant
outreach — not spam. Claude drafts every message with the personalization
filled in; Jack approves the batch before anything is sent.

`{{...}}` fields are filled per-lead by Claude from the lead list.
